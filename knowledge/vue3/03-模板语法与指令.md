# Vue3 模板语法与常用指令

## 插值与表达式

双大括号 `{{ }}` 内是 JavaScript 表达式，不是语句。可以写三元、运算、函数调用，但不能写 `if`、`for`、变量声明。

```vue
<p>{{ count * 2 }}</p>
<p>{{ ok ? '是' : '否' }}</p>
<p>{{ list.filter(i => i.done).length }}</p>
```

表达式里不要放有副作用的调用（如 `Math.random()`、请求函数），因为模板会在每次重渲染时执行。复杂逻辑放 `computed`。

## 指令一览

| 指令 | 简写 | 说明 |
|---|---|---|
| `v-bind` | `:` | 绑定属性/动态 prop |
| `v-on` | `@` | 绑定事件 |
| `v-model` | — | 双向绑定表单或组件 |
| `v-if` / `v-else-if` / `v-else` | — | 条件渲染，切换时销毁重建 |
| `v-show` | — | 条件显示，仅切换 `display` |
| `v-for` | — | 列表渲染 |
| `v-text` / `v-html` | — | 设置文本 / HTML（后者有 XSS 风险） |
| `v-once` | — | 只渲染一次 |
| `v-memo` | — | 缓存子树，依赖不变时跳过更新 |

## v-if 与 v-show 的区别

| | v-if | v-show |
|---|---|---|
| 是否保留 DOM | 不保留，销毁重建 | 保留，切换 `display: none` |
| 首次渲染成本 | 条件为假时几乎为零 | 总是渲染 |
| 切换成本 | 高（涉及组件销毁与重建） | 低（只改样式） |
| 适用场景 | 条件很少变化 | 频繁切换（tab、弹层） |

一个容易忽略的差别：`v-if` 会触发子组件的 `onUnmounted` / `onMounted`，`v-show` 不会。如果子组件里有定时器或事件监听，用 `v-show` 隐藏时它们仍在运行。

## v-for 的三个要点

**1. key 不要用 index**

```vue
<!-- 错误：删除第一项后，后续所有项 key 都变了 -->
<li v-for="(item, i) in list" :key="i">{{ item }}</li>

<!-- 正确：用稳定唯一标识 -->
<li v-for="item in list" :key="item.id">{{ item.name }}</li>
```

用 index 作 key 时，列表重排会复用错误的 DOM 节点，表现为输入框内容串行、动画错位、复选框状态错乱。

**2. 不要和 v-if 写在同一个元素上**

Vue3 中 `v-if` 的优先级高于 `v-for`，所以 `v-if` 拿不到 `v-for` 的循环变量，直接报错。

```vue
<!-- 错误 -->
<li v-for="item in list" v-if="item.active">{{ item.name }}</li>

<!-- 正确做法一：外层套 template -->
<template v-for="item in list" :key="item.id">
  <li v-if="item.active">{{ item.name }}</li>
</template>

<!-- 正确做法二：先过滤 -->
<li v-for="item in activeList" :key="item.id">{{ item.name }}</li>
```

第二种更好，因为过滤结果可以用 `computed` 缓存。

**3. 遍历对象与数字**

```vue
<li v-for="(value, key, index) in obj" :key="key">{{ index }} - {{ key }}: {{ value }}</li>
<li v-for="n in 5" :key="n">{{ n }}</li>
```

## 动态参数

`v-bind` 和 `v-on` 支持动态参数，用方括号：

```vue
<a :[attrName]="url">链接</a>
<button @[eventName]="handler">按钮</button>
```

方括号内是表达式，必须求值为字符串或 `null`。动态参数不支持空格和引号，复杂表达式建议用 `computed` 算好再传。

## 事件修饰符

| 修饰符 | 作用 |
|---|---|
| `.stop` | 阻止冒泡（`event.stopPropagation()`） |
| `.prevent` | 阻止默认行为（`event.preventDefault()`） |
| `.self` | 只有事件目标是元素本身时才触发 |
| `.once` | 只触发一次 |
| `.capture` | 用捕获模式监听 |
| `.passive` | 提升滚动性能，不能与 `.prevent` 同用 |

```vue
<form @submit.prevent="onSubmit">
  <div @click.self="close">点击内部不关闭</div>
</form>
```

## v-model 的修饰符

| 修饰符 | 作用 |
|---|---|
| `.lazy` | 改为 `change` 事件触发，而不是每次输入 |
| `.number` | 自动转数字 |
| `.trim` | 自动去首尾空格 |

```vue
<input v-model.lazy.trim="keyword" />
<input v-model.number="age" type="number" />
```

## class 与 style 绑定

```vue
<div :class="{ active: isActive, 'text-danger': hasError }"></div>
<div :class="[baseClass, isActive ? 'on' : '']"></div>
<div :style="{ color: textColor, fontSize: size + 'px' }"></div>
```

数组写法里可以混入对象；`:class` 与静态 `class` 会合并，不会互相覆盖。
